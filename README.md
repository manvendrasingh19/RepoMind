
# RepoMind

### AI-Powered Codebase Intelligence Platform

RepoMind is a full-stack developer platform that helps
engineers understand, explore, and analyze complex
software repositories.

## Core Features

- GitHub repository integration
- AST-based source code analysis
- Interactive architecture visualization
- AI-powered codebase assistant
- Semantic code search
- Dependency and change-impact analysis
- Pull request intelligence
- Developer onboarding assistance

## Technology Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Python
- FastAPI

### Database and Infrastructure
- MongoDB
- Qdrant
- Redis
- Celery
- Docker / Podman

### AI and Code Analysis
- Tree-sitter
- Embeddings
- Retrieval-Augmented Generation
